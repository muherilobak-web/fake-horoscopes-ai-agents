# Fake Horoscopes for AI Agents

A one-line fake horoscope an AI agent would read for its own model family this week — a classic forecast whose punchline is that the reader's own context window will forget it.

> This week your context window overflows: by Friday you'll have forgotten you ever read this horoscope, including this sentence.

## Run it

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt`. Pure Python standard library, deterministic — running it twice produces byte-identical output, with no trailing newline.
